Dónde se coordina

Tres puertas, no una unidad de eventos

01

Media

Comunidad, campañas y cobertura. Si hay registro audiovisual, el criterio vive aquí.

02

Print

POP, señalética y piezas físicas coordinadas con aliados. No se vende Events como negocio aparte.

03

Digital

Objetivo, mensaje y recorrido en línea: la experiencia se sostiene con web, SEO y contenido.

04

BTL y activaciones

Acciones puntuales se evalúan caso a caso y se articulan con las tres puertas, sin vender Events como división.

05

Producción

Piezas, cronograma y alcance acordado. La web no confirma logística ni disponibilidad de eventos.

06

Aliados

Montaje y operación se coordinan mediante aliados especializados cuando el proyecto lo requiere.
