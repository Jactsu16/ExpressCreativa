# Portafolio de ExpressCreativa

Coloca aquí únicamente imágenes cuya publicación haya sido autorizada.

Para cada proyecto conviene registrar:

- nombre interno del proyecto;
- categoría;
- fecha aproximada;
- servicio realizado;
- autorización de cliente y personas reconocibles;
- texto alternativo descriptivo;
- crédito del fotógrafo;
- versión web optimizada y archivo original separado.

No deben publicarse pruebas no seleccionadas, datos de clientes, menores sin
autorización verificable ni material que utilice marcas de terceros sin permiso.
