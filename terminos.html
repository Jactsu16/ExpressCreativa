Términos de uso

Versión preoperativa · Actualizada el 28 de julio de 2026

No hay venta activa: el sitio es informativo y de preparación. No existe checkout, no se reciben pagos y ninguna solicitud confirma precio, inventario, fecha de entrega o producción.

1. Alcance actual

La web ofrece información, calculadoras, herramientas de preimpresión y medios para iniciar una conversación. Una cotización o contrato comercial solo podrá existir mediante una aceptación posterior, expresa y documentada.

2. Print Lab

Las herramientas producen estimaciones y previsualizaciones referenciales. El resultado puede variar según pantalla, perfil de color, tela, tinta, equipo y técnica. Antes de producir deberán aprobarse por escrito arte, medidas, posición, colores, cantidades, tallas y muestra cuando corresponda.

3. Archivos y propiedad intelectual

Al utilizar un archivo declaras que tienes autorización para procesarlo y compartirlo. No debes utilizar marcas, fotografías, personajes, tipografías o diseños ajenos sin licencia. ExpressCreativa podrá rechazar proyectos que razonablemente infrinjan derechos de terceros.

4. Producción mediante aliados

ExpressCreativa proyecta gestionar trabajos mediante talleres y proveedores especializados. No se afirmará que los productos se fabrican en instalaciones propias cuando no sea cierto. Las responsabilidades comerciales definitivas se establecerán en la cotización y contrato aplicables.

5. Uso permitido

No puedes intentar vulnerar la web, automatizar abuso, introducir código malicioso, cargar contenido ilegal o usar las herramientas para afectar derechos de terceros.

6. Disponibilidad

Las herramientas pueden cambiar o suspenderse durante la etapa de prueba. No se garantiza disponibilidad ininterrumpida ni que todo archivo sea compatible.

7. Ley aplicable y contacto

Estos términos se interpretan de acuerdo con las normas aplicables de la República de Panamá. Para consultas escribe a expresscreativa.pa@gmail.com. Las condiciones comerciales completas se publicarán antes de activar ventas.
